# NITI — คลังความรู้กฎหมายไทย

เว็บไซต์ Static HTML สำหรับการศึกษาและค้นคว้าหัวข้อกฎหมายไทย พร้อมลิงก์ไปยังแหล่งข้อมูลทางการ

## สิ่งที่มีในเว็บไซต์

- ดีไซน์ภาษาไทยแบบ Responsive สำหรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- หมวดศึกษากฎหมาย 4 หมวด ได้แก่ ปกครอง แพ่งและพาณิชย์ อาญา และวิธีพิจารณาความ
- ช่องค้นหาหัวข้อแบบกรองทันทีภายในหน้าเว็บ
- ลิงก์ไปยังเว็บไซต์ราชกิจจานุเบกษา สำนักงานคณะกรรมการกฤษฎีกา ศาลปกครอง และศาลยุติธรรม
- ไม่มีการเก็บข้อมูลผู้ใช้ ไม่มี Backend และไม่ต้องติดตั้งแพ็กเกจ

## เปิดเผยแพร่ด้วย GitHub Pages

1. เข้า **Settings** ของ Repository นี้
2. เลือก **Pages** จากเมนูด้านซ้าย
3. ใน **Build and deployment → Source** เลือก **Deploy from a branch**
4. ใน **Branch** เลือก **main** และ **/(root)** แล้วคลิก **Save**
5. ตรวจสอบ URL: https://chakritago.github.io/niti.github.io/

หากยังไม่เห็นเว็บไซต์ ให้ตรวจสอบสถานะการเผยแพร่ที่เมนู **Actions** หรือ **Settings → Pages** ก่อน

> **หมายเหตุ:** Repository ชื่อ `niti.github.io` เป็น *project site* ของบัญชี `chakritago` จึงใช้ URL ที่มี `/niti.github.io/` ต่อท้าย หากต้องการ URL หลัก `https://chakritago.github.io/` ต้องใช้ Repository ชื่อ `chakritago.github.io`

## ปรับแต่งเว็บไซต์

แก้ไขไฟล์ [index.html](./index.html) ได้โดยตรง ตัวเว็บไซต์ใช้ HTML, CSS และ JavaScript ในไฟล์เดียว ทุกครั้งที่ Commit ลง `main` ระบบ GitHub Pages ที่ตั้งค่าแล้วจะนำไฟล์รุ่นใหม่ไปเผยแพร่

เว็บไซต์นี้เป็นแหล่งจัดหมวดข้อมูลเพื่อการศึกษา ไม่ใช่หน่วยงานรัฐหรือบริการให้คำปรึกษากฎหมาย
