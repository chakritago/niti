# NITI — คลังความรู้กฎหมายไทย

เว็บไซต์ Static HTML สำหรับการศึกษาและค้นคว้าหัวข้อกฎหมายไทย พร้อมลิงก์ไปยังแหล่งข้อมูลทางการ

## สิ่งที่มีในเว็บไซต์

- ดีไซน์ภาษาไทยแบบ Responsive สำหรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- หมวดศึกษากฎหมาย 4 หมวด ได้แก่ ปกครอง แพ่งและพาณิชย์ อาญา และวิธีพิจารณาความ
- ช่องค้นหาหัวข้อแบบกรองทันทีภายในหน้าเว็บ
- ลิงก์ไปยังเว็บไซต์ราชกิจจานุเบกษา สำนักงานคณะกรรมการกฤษฎีกา ศาลปกครอง และศาลยุติธรรม
- ไม่มีการเก็บข้อมูลผู้ใช้ ไม่มี Backend และไม่ต้องติดตั้งแพ็กเกจ

## Design System — Minimal / Material-inspired

หน้าแรก หน้าติว และหน้าแผนอ่านสอบใช้ชุดการออกแบบเดียวกันผ่าน [`theme.css`](./theme.css) และ [`theme.js`](./theme.js) โดยยึดแนวคิดของ **Material Design 3** ในเรื่องลำดับชั้นข้อมูล ระยะห่าง สีตามบทบาท และความเข้าถึงได้ (เป็นดีไซน์ที่พัฒนาเอง ไม่ใช่ส่วนประกอบหรือใบรับรองจาก Google)

- **Primary Blue**: `#1967D2` สำหรับการกระทำหลัก ลิงก์ และสถานะเลือก; **Primary Container**: `#E8F0FE` สำหรับพื้นไฮไลต์; **Background**: `#F8FAFD`; **Surface**: `#FFFFFF`; **Text**: `#202124` (ในโหมดสว่าง)
- ใช้ฟอนต์ไทยจาก **Google Fonts**: `Sarabun` (ข้อความยาว ข้อสอบ ธงคำตอบ) และ `IBM Plex Sans Thai` (หัวเรื่อง/ปุ่ม/เมนู) พร้อมฟอนต์สำรองของระบบเมื่อไม่สามารถโหลดจาก CDN ได้
- **สำหรับผู้ใช้วัย 50+ หรือผู้ที่ต้องการตัวอักษรใหญ่:** ขนาดตั้งต้น **24px** พร้อมปุ่ม `ก−` / `ก+` ในเมนูทุกหน้า ปรับได้ **20 / 22 / 24 / 26 / 28px**; ข้อสอบ เฉลย กล่องสนทนา และเนื้อหาทั่วไปปรับใหญ่ขึ้น พร้อมระยะบรรทัดประมาณ 1.85–2 เท่าของขนาดตัวอักษร
- การเลือกระดับตัวอักษรเก็บใน `localStorage` ด้วยคีย์ `niti-font-level-v1` และใช้ร่วมกันระหว่างหน้าแรกกับหน้าติว โดยไม่ต้องล็อกอิน; ผู้ใช้ยังสามารถใช้ Browser Zoom ได้ตามปกติ
- ปุ่มทรง pill, การ์ดมุมโค้ง 16–24px, พื้นหลังเรียบ, เงาเล็กน้อย, เส้นขอบคอนทราสต์พอเหมาะ และการจัดวาง responsive
- ปุ่ม **โหมดมืด / โหมดสว่าง** ในเมนูของทั้งสองหน้า; ตั้งค่าแรกเริ่มตามระบบปฏิบัติการ รองรับการเลือกเองและจำตัวเลือกไว้ใน `localStorage` ภายใต้คีย์ `niti-theme-v1` ใช้ร่วมกันทั้งเว็บไซต์
- สีโหมดมืดใช้ชุดสีที่มี contrast และ semantic roles แยกต่างหาก ไม่กลับสีผ่าน CSS filter
- ลดการเคลื่อนไหวตาม `prefers-reduced-motion`, เน้น keyboard focus state และขนาดกดของปุ่มหลัก

## คู่มืออ่านสอบ: แผน 7 วัน + ความถี่ในคลังตัวอย่าง

หน้าใหม่ [study.html](./study.html) สำหรับเรียนเป็นขั้น เปิดที่ **https://chakritago.github.io/niti/study.html**

- [`study-guide.js`](./study-guide.js) รวมคำแนะนำ 6 หัวข้อ เน้นมาตราสำคัญ วิธีจับประเด็น วิธีจำ จุดที่มักพลาด ตารางอ่าน 7 วัน และเทคนิคจำ **15 ข้อ**; [`study.js`](./study.js) คำนวณสถิติจาก `exam-data.js` และแสดงแผนแบบโต้ตอบ; [`study.css`](./study.css) ให้ดีไซน์การเรียนรู้ที่แยกเนื้อหาด้วยสีอย่างมีลำดับ
- แสดงความถี่ **จาก 15 โจทย์ที่มีในคลังเท่านั้น** ไม่อ้างว่าเป็นอัตราออกสอบทั้งหมดหรือความน่าจะเป็นของข้อสอบครั้งถัดไป
- จัดลำดับอ่านตามหัวข้อที่พบในคลัง พร้อมรายการเลขมาตรา แนวโจทย์ องค์ประกอบ และคำจำสั้น ๆ สำหรับแต่ละหัวข้อ
- แผนอ่าน **7 วัน** ทำเครื่องหมายวันสำเร็จได้ บันทึกใน `localStorage` ของเบราว์เซอร์เครื่องนั้น และมีทางลัดไปข้อสอบที่เกี่ยวข้อง
- หัวข้อทริคจำรายข้อพร้อมลิงก์ **แหล่งข้อสอบต้นทางครบทุกข้อ** และปุ่มเปิดข้อสอบที่ระบุโดยตรงด้วย `quiz.html?exam=...`
- หน้า `quiz.html` มีคำชี้นำก่อนตอบแยกข้อ จาก [`study-companion.js`](./study-companion.js) และเชื่อมกลับมาคู่มืออ่านสอบ
- เพิ่มชุดสีตามหน้าที่: ฟ้าสำหรับข้อมูลอ้างอิง เขียวอมฟ้าสำหรับหลักคิด ส้มสำหรับสถานการณ์โจทย์ และม่วงสำหรับทริคจำ โดยรักษาสีหลักของ NITI เป็นน้ำเงิน

**คำเตือนด้านความน่าเชื่อถือ:** สิ่งที่เรียกว่า “พบบ่อย” เป็นเพียงการนับข้อมูล 15 ข้อที่คัดเลือกจาก 5 ภาคเรียน ไม่ใช่การสำรวจข้อสอบทุกปี ทุกภาคเรียน และไม่ใช่คำรับรองว่าจะออกสอบเรื่องใดครั้งต่อไป เทคนิคและเฉลยเป็นบทเรียนเรียบเรียงใหม่ ควรตรวจสอบกฎหมายปัจจุบันกับสำนักงานคณะกรรมการกฤษฎีกาเสมอ

## ระบบติวเขียนข้อสอบกฎหมายลักษณะทรัพย์สินและที่ดิน

เปิดได้จากหน้าแรกหรือที่ **https://chakritago.github.io/niti/quiz.html** (หลัง GitHub Pages เผยแพร่สำเร็จ)

- ไฟล์ `quiz.html`: หน้าฝึกตอบข้อสอบอัตนัย รองรับมือถือ พร้อมค้นหาและกรองหมวด/ปีการศึกษา จับเวลา 25 นาทีต่อข้อ ส่งออกร่างคำตอบเป็น .txt
- **โหมดสอนแบบแชต:** หน้าเดิมมีโค้ชถามตอบ 4 ขั้นอย่างเป็นลำดับ, คำใบ้รายข้อ, กล่องตอบแชต, บันทึกคำตอบลงกระดาษคำตอบ และจำบทสนทนาในเครื่อง **เป็นระบบบทเรียนกฎเกณฑ์ ไม่ใช่โมเดล AI และไม่สามารถตรวจคำตอบภาษาไทยแบบ ChatGPT ได้**
- **เรียนต่อกับ ChatGPT จริง:** ปุ่ม ‘คัดลอกโจทย์สำหรับ ChatGPT’ สร้างคำสั่งติวแบบ Socratic พร้อมแหล่งข้อสอบรายข้อให้คัดลอก แล้วผู้เรียนกดลิงก์ ChatGPT และวางข้อความเอง **ไม่มีการส่งคำตอบส่วนตัวหรือ API key จากเว็บไซต์**
- **โจทย์ต้นฉบับพร้อมธงคำตอบ:** ปุ่มแสดงเว็บไซต์ผู้เผยแพร่ต้นทางแบบฝังในกรอบ iframe และปุ่มเปิดต้นฉบับในแท็บใหม่เสมอ **เว็บไซต์ต้นทางอาจบล็อกการฝัง iframe**; การแสดงต้นฉบับจึงขึ้นอยู่กับข้อกำหนดของเว็บไซต์ภายนอก
- **เฉลยตัวอย่าง:** เปิดดูคำตอบแบบ IRAC 4 ส่วนที่เรียบเรียงขึ้นใหม่ครบ 15 ข้อจาก `tutor-answers.js` พร้อมลิงก์อ่านธงคำตอบฉบับเต็มที่ต้นทาง; ไม่คัดลอกเนื้อหาข้อสอบเต็มไว้บน GitHub
- `tutor.js`: ควบคุมบทสนทนา คำใบ้ แสดงต้นฉบับฝัง และเฉลยในหน้าเดียวกัน; `tutor-answers.js`: ข้อมูลเฉลยที่เขียนใหม่รายข้อ
- ไฟล์ `exam-data.js`: โจทย์สรุปถอดความจากข้อสอบที่เว็บไซต์ **เอ็มเจชีทรามฟรี** เผยแพร่ จำนวน **15 ข้อ** จาก 5 ภาคเรียน โดยเก็บรหัสข้อ, รหัสวิชา, ปี, ภาค, เลขข้อ, ประเด็น, มาตรา, แนววินิจฉัย และ **`sourceUrl` อ้างอิงรายข้อ**
- ใช้วิธีตอบแบบ **IRAC**: ระบุประเด็น (Issue), วางหลักกฎหมาย (Rule), ปรับบท (Application), สรุป (Conclusion)
- เกณฑ์ประเมินตนเอง 4 ข้อ ข้อละ 25 คะแนน; คะแนนคำนวณจากรายการที่ผู้เรียนทำเครื่องหมาย **ไม่ใช่การตรวจความถูกต้องด้วย AI**
- ร่างคำตอบและผลประเมินเก็บใน `localStorage` ของเบราว์เซอร์ ไม่มี Backend ไม่มีบัญชีผู้ใช้ และข้อมูล **ไม่ซิงก์ข้ามเครื่อง**
- ลิงก์แหล่งข้อสอบหลัก: https://mjsheetramfree.com/law2001-la201-lw204-kdhmay-phaeng-laea-phanichy-wa-dwy-thraphy/

### นโยบายแหล่งอ้างอิงสำหรับข้อสอบ

1. **โจทย์ทุกข้อใน `exam-data.js` ต้องมี `sourceUrl` ที่เปิดไปยังหน้าข้อสอบรายภาคเรียนซึ่งปรากฏข้อดังกล่าวจริง** ห้ามใช้ลิงก์หน้าแรกแทนลิงก์ที่เฉพาะเจาะจงกว่า
2. ข้อความในแอปเป็น **สรุปถอดความเพื่อฝึกเขียน** ไม่ใช่คำถาม/เฉลยคัดลอกเต็มต้นฉบับ และเว็บไซต์ต้นทางเป็นเว็บไซต์รวบรวมข้อสอบ **ไม่ใช่ต้นฉบับรับรองจากมหาวิทยาลัย**
3. หากเพิ่มโจทย์ฝึกสร้างขึ้นเอง ต้องติดป้าย `โจทย์ฝึกแต่งใหม่` และให้ลิงก์หลักกฎหมายต้นทาง ไม่แอบอ้างว่าเป็นข้อสอบที่เคยออก
4. ห้ามบันทึกข้อสอบที่ยังตรวจสอบแหล่งอ้างอิงไม่ได้ไว้ในรายการข้อสอบจากต้นทาง
5. ธงคำตอบและเลขมาตราเป็นแนวการเรียน ควรเทียบต้นฉบับและตรวจสอบกฎหมายปัจจุบันจาก https://www.krisdika.go.th/ เสมอ

## เปิดเผยแพร่ด้วย GitHub Pages

1. เข้า **Settings** ของ Repository นี้
2. เลือก **Pages** จากเมนูด้านซ้าย
3. ใน **Build and deployment → Source** เลือก **Deploy from a branch**
4. ใน **Branch** เลือก **main** และ **/(root)** แล้วคลิก **Save**
5. ตรวจสอบ URL: https://chakritago.github.io/niti/

หากยังไม่เห็นเว็บไซต์ ให้ตรวจสอบสถานะการเผยแพร่ที่เมนู **Actions** หรือ **Settings → Pages** ก่อน

> **หมายเหตุ:** Repository ชื่อ `niti` เป็น GitHub Pages แบบ *project site* ของบัญชี `chakritago` จึงมี URL `https://chakritago.github.io/niti/` หากต้องการ URL หลัก `https://chakritago.github.io/` ต้องใช้ Repository ชื่อ `chakritago.github.io`

## ปรับแต่งเว็บไซต์

แก้ไขหน้าแรกได้ที่ [index.html](./index.html), คู่มือที่ [study.html](./study.html) และระบบติวได้ที่ [quiz.html](./quiz.html), [exam-data.js](./exam-data.js), [tutor.js](./tutor.js) และ [tutor-answers.js](./tutor-answers.js) โดยตรง ทุกครั้งที่ Commit ลง `main` ระบบ GitHub Pages ที่ตั้งค่าแล้วจะเผยแพร่การแก้ไข

เว็บไซต์นี้เป็นแหล่งจัดหมวดข้อมูลเพื่อการศึกษา ไม่ใช่หน่วยงานรัฐหรือบริการให้คำปรึกษากฎหมาย
